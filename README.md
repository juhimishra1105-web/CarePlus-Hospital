🏥 CarePlus Hospital Management System

About the Project

CarePlus is a web-based Hospital Management System designed to simplify basic hospital operations through a clean and user-friendly interface.

Features

- Patient Management: Register and view patient records.
- Doctor Management: Add and manage doctor information.
- Appointment Management: Book and view appointments.
- Diet & Nutrition: Create and save patient diet plans.
- Bed Management: Track bed availability and patient allocation.

Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in a web browser.
